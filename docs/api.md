## `<starter/app>`

The root: the theme, the screens of the current route, and the tabs under them (a sidebar
beside them in a wide window). Routes:
"/" (Home), "/packages", "/packages/:name" and "/settings"; on the web they are the URL.

### apply_theme

```eskiu
void apply_theme()
```

The theme the user chose, or the system's appearance.

### Screen

```eskiu
void Screen(*Router router, string route)
```

The screen for `route`: a package's screen for /packages/:name, Packages, Settings, else
Home.

### App

```eskiu
void App()
```

The root: the theme, the status bar, the router's screens, the bottom tabs (or the
sidebar in a wide window) and the toast host.


## `<starter/components/tabs>`

The tab bar along the bottom: a tab per section, the current one in the theme's color. Each
tab is a route at the root of the stack; a tab's screens push on top of it.

### AppTab

```eskiu
struct AppTab { string route; string icon; string title; }
```

A section of the app: its route at the root of the stack, its icon and its title.

### kTabs

```eskiu
const int kTabs = 3;
```

The number of sections (tabs).

### tab

```eskiu
AppTab tab(int i)
```

Each icon ends in U+FE0E, so the platforms draw it as text, in the tab's color, not as an emoji.

### tab_of

```eskiu
int tab_of(string route)
```

The tab a route belongs to: the one whose route starts it.

### BottomTabs

```eskiu
void BottomTabs(*Router router)
```

The tab bar: a tab per section, the current one in the theme's color; a tab resets the
stack to its route. Under it, room for the home indicator.

### SidebarItem

```eskiu
void SidebarItem(*Router router, int i, bool on)
```

A section in the sidebar: its icon and name, the current one in the theme's color, and a
shade under the pointer.

### Sidebar

```eskiu
void Sidebar(*Router router)
```

The sections down the side of a wide window, in place of the tab bar.

### PageBody

```eskiu
void PageBody(int gap, escaping fn()->void content)
```

A screen's content, padded; in a wide window, centered at a width that reads well.

### Page

```eskiu
void Page(escaping fn()->void content)
```

A tab's screen: it scrolls, starts under the status bar (the app draws edge to edge) and
pads its content.

### ScreenTitle

```eskiu
void ScreenTitle(string eyebrow, string title)
```

A screen's title, large, with an optional line above it.


## `<starter/main>`

The app's start: the model and the root. `ui serve` runs it in the browser and rebuilds on
each change; `ui serve ios` and `ui serve android` do the same on a simulator or device.

### ui_app_start

```eskiu
void ui_app_start(int which)
```

The hosts call it once at launch: the app draws edge to edge, the model starts and the
root is mounted.

### ui_app_stop

```eskiu
void ui_app_stop()
```

The hosts call it when the app ends: frees the model.


## `<starter/model>`

The app's state that outlives its screens: the router, the theme the user chose (saved), and
the packages loaded from the network. Screens read it through its signals.

### ThemeMode

```eskiu
enum ThemeMode { ThemeSystem, ThemeLight, ThemeDark }
```

The theme the user chose: follow the system, always light, or always dark. Saved as its
number under the storage key "theme".

### Repo

```eskiu
struct Repo { String name; String description; String url; int stars; }
```

A package of the Eskiu project on GitHub.

### LoadState

```eskiu
enum LoadState { LoadIdle, LoadBusy, LoadDone, LoadFailed }
```

Loading the list: not started, in flight, loaded, or failed (with the reason in model.error).

### Model

```eskiu
struct Model {
    *Router router;
    *Signal<int> theme;
    *Signal<int> load;
    *Signal<int> repos_version;
    List<Repo> repos;
    String error;
}
```

The app's state: the router, the theme, the load state of the package list, a counter
bumped each time the list is replaced, the list itself and the reason of the last failed
load.

### model_start

```eskiu
void model_start()
```

Creates the router at "/", the theme signal (from the saved choice, else ThemeSystem)
and the load signals.

### repos_clear

```eskiu
void repos_clear(List<Repo>* repos)
```

Frees each repository's strings and empties the list (its storage is kept).

### model_stop

```eskiu
void model_stop()
```

Frees everything model_start and the loads made.

### model_set_theme

```eskiu
void model_set_theme(int mode)
```

Switches the theme to `mode` (a ThemeMode) and saves it on the device.

### repos_parse

```eskiu
bool repos_parse(string body, List<Repo>* out)
```

GitHub's answer for the organization's repositories (a JSON array) into `out`, the most
starred first; false when it is not one.

### model_load_repos

```eskiu
void model_load_repos()
```

Load the packages (again): the Packages screen shows the state as it goes.

### model_repo

```eskiu
*Repo model_repo(string name)
```

The repository named `name`, or null.


## `<starter/screens/detail>`

A package's screen: what it is, its stars, and a link to it.

### DetailScreen

```eskiu
void DetailScreen(*Router router, string name)
```

The screen of the package `name`: a navigation bar with Back (to the list when the
screen was opened by a link), then its name, stars and description with buttons to open
it on GitHub and to share it, loading the list first if needed.


## `<starter/screens/home>`

Home: a welcome, the two other sections, and what to change first.

### Shortcut

```eskiu
void Shortcut(*Router router, string icon, string title, string detail, string route)
```

A card that opens the section `route` (resetting the stack to it), with an icon, a title
and a line under it.

### Step

```eskiu
void Step(int number, string text)
```

A numbered step: `number` in a circle, then `text`.

### HomeScreen

```eskiu
void HomeScreen(*Router router)
```

Home: a welcome banner, shortcuts to the other sections, and the first things to change
in the template.


## `<starter/screens/packages>`

Packages: the Eskiu project's repositories from GitHub's API, pulled again on refresh;
a row opens the package's screen.

### package_color

```eskiu
int64 package_color(string name)
```

A tile's color from the package's name, so each keeps its own.

### PackageCard

```eskiu
void PackageCard(*Router router, int i)
```

A package as a card: its initial on its color, its name, what it is and its stars.

### PackagesScreen

```eskiu
void PackagesScreen(*Router router)
```

Packages: the repositories as cards, two a row (three in a wide window), pulled again on
refresh, with the loading and error states; the list loads the first time the screen
shows.


## `<starter/screens/settings>`

Settings: the theme (saved, so the app opens with it), and about the app.

### SettingsScreen

```eskiu
void SettingsScreen(*Router router)
```

Settings: the theme as a segmented control (saved on the device), and about the app (the
platform it runs on, a link to eskiu-lang/ui).
